QA Suite: SP1 Combined Bug Fixes (vgbo, 05lt, u29o, pyxj.4)
=============================================================

This QA suite specifies end-to-end test workflows that operate at the
user interface (CLI + output file inspection) without using internal
project APIs. All tests run via shell commands and inspect output files.

Prerequisites:
- uv environment synced (uv sync)
- Test fixtures available in tests/stpa/fixtures/
- A writable temp directory for output

--------------------------------------------------------------

  Setup:

  Action:
